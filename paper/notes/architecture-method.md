**Terminology trap for the paper:** in this repo **"F64" is not float64**. It is a clip *geometry*: 64 encoder/cross-attention frames (16 chunks × 1,280 PCM samples = 20,480 samples = 1.28 s at 16 kHz; 50 Hz features). Likewise F500/W500/T67/Q67 are frame/window/token/query capacity envelopes (`C/docs/TAALAS-K64-NATIVE-WORKLOAD.md`, `C/docs/ROUTEVOICE-V1-INTEGRATION-2026-10-11.md` §snapshot). "Bit-exact" means bitwise-identical integer values and IEEE FP32 words versus a frozen software reference (see §5).

## 1. Model

- **Model:** Moonshine Tiny Streaming English, MIT licence, 34,000,000 parameters reported; repo `moonshine-ai/moonshine` rev `234f60fa…`; artifacts `tiny-streaming-en/quantized_26_08_21`; selected set **45,233,659 bytes** (`version1/models/manifest.json`; `README.md` model table).
- **Graphs:** six ORT-format-v6 graphs (frontend.weights, frontend.model, encoder, adapter, cross_kv, decoder_kv): 881 optimized nodes, 485 initializers, 44,435,754 initializer bytes; custom ops include 48 `MatMulIntegerToFloat`, 48 `DynamicQuantizeMatMul`, 18 `FusedMatMul`, 8 `QuickGelu`, 2 `SkipLayerNormalization` (`version1/docs/research/model-operator-inventory.md` §3.1–3.2).
- **Geometry:** width 320, depth 6 (encoder) + 6 (decoder), 8 heads, head dim 40, vocabulary 32,768, feature frame 80 samples, lookahead 16 (`version1/docs/research/model-operator-inventory.md` §3.2). FF projection 1,280×320 (`C/docs/ROUTEVOICE-PROPOSED-PHYSICAL-GOAL-2026-10-13.md` §Selected projection). Tied embedding/head `embedding.weight_quantized` UINT8 32,768×320 with verified transpose alias (`C/docs/TAALAS-TIED-HEAD.md` l.121–122); ORT stores a 10,485,760-byte duplicate (`version1/models/stt_moonshine/MODEL.md` l.44).
- **Tokenizer:** `tokenizer.bin`, 249,974 bytes; 32,768-way output (`version1/models/stt_moonshine/MODEL.md` l.35). Type not documented (SentencePiece/BPE not stated).
- **Audio frontend:** no FFT/Mel. Per 80-sample (5 ms) group: mean/variance normalization (CMVN) → asinh → learned 80→320 linear → QuickGELU → 320→640 and 640→320 kernel-5 stride-2 Conv1d → 50 Hz / 20 ms features; persistent frontend state 15,692 B (`version1/docs/research/model-operator-inventory.md` §3.3). VAD, resampling, tokenizer decode and decode loop are in the native runtime, outside the graphs (same).
- **Quantized candidate used by the chip: "K64"** = `codebook-4bit-optimal-rectangular-k64`, manifest SHA-256 `a9ac4a4c…70cc` (`C/docs/TAALAS-K64-QUALITY-RESULT.md`; `C/docs/DIE-COUNT-PROOF-2026-09-19.md` §Model). Frontend weights keep the source INT8 affine form; floating ops (frontend, head, softmax, norms) remain. Not W4A4 (`C/docs/TAALAS-K64-QUALITY-RESULT.md` para 1).
- **Reference meaning:** RTL exactness is to the *frozen executable K64* tensors (e.g. `val_89_quantized` SHA `3bdff3a2…`), *not* to the pre-codebook original; the original differs at 291,832 of 409,600 positions of the selected projection (`O/fabric-k64/RESULTS.md` §Identity; `O/fabric-k64/CONTRACT.md` last para). Projection oracle = independent dense NumPy reference over the executable tensor bytes plus a scheduled shared-partial reference; 320 captured outputs also match a fresh ORT run bit-for-bit (`C/docs/TAALAS-SHARED-PARTIAL-PRODUCTS.md` §Floating output). Full-recognizer oracle = 18 frozen boundary/output files (incl. 12 cross-attention banks, final token rows) + 163,840 full-vocabulary logits (5 tokens × 32,768) + token IDs + rendered text (`C/docs/ROUTEVOICE-V1-INTEGRATION-2026-10-11.md` §snapshot).
- **Main clip:** F64 "Switch on the lights", tokens `[28176, 373, 278, 26068, 2]`, 312,578,649 common clocks (`F/w11-taalas-e2e/RESULTS.md`). Extra Taalas-storage clips: wispr-031-seg1 "Plant present." (309,272,913 clocks) and software-1919-142785-0022-seg0 "Seasonable." (308,976,820 clocks; 19,456 samples + 1,024 declared silence) (same, §Consolidated corpus results).

Development-set saved-output WER on 26 complete recordings: RTL 22/125 words (17.60%) vs source streaming controller 34/125 (27.20%) (`C/docs/ROUTEVOICE-V1-CURRENT-DESIGN-2026-10-12.md` l.149); on 34 recordings 29/167 (17.37%) vs 41/167 (24.55%) (same, l.41). ## 2. Weight representation

- **Index width / codebook:** 4-bit index per weight into a local book of **16 UINT8 representatives**, one book per **64 contiguous inputs × 1 output** ("K64"). Every encoder/decoder weight image uses exactly 16 distinct UINT8 values per 64×1 group, so index+book is exact (`OVERNIGHT-PROGRESS.md` §Baseline facts; `F/BRIEF-codex-W11.md`). The tied embedding uses corresponding feature blocks within each vocabulary row (`C/docs/TAALAS-K64-QUALITY-RESULT.md` §Fixed candidate). Not per-matrix and not per-row: per (64-row domain, output column). In RTL, `codebook_row_domain = row >> 6` (`O/fabric-k64/rtl/engine.sv` l.613).
- **Counts:** 98 packed records ("98 unique matrices … across six original shape classes"), **31,457,280 four-bit selections = 125,829,120 bits**, **491,520 local books**, 15,728,640 packed-index bytes, 7,765,892 representative bytes (`C/docs/TAALAS-K64-QUALITY-RESULT.md` §Fixed candidate; `F/w13-arrays/RESULTS.md` l.5). Breakdown: 7,372,800 encoder + 12,288,000 decoder incl. cross-K/V + 1,310,720 position + 10,485,760 tied embedding/head (`C/docs/TAALAS-INTEGRATED-BUDGET.md` §What is actually counted). INFERRED: 98 = 96 integer projection matrices (`plan.md` M3 "all 96 integer matrices") + tied head + position table; 96 = 6×6 encoder (Q,K,V,O,FF1,FF2) + 6×10 decoder (self QKVO, cross Q/O, cross K/V, FF up/down).
- **Per projection (selected 1,280×320 FF-out, `node_MatMul_86_quant`):** 409,600 weights, 6,400 books, 102,400 representatives, 1,638,400 index bits (`O/fabric-k64/CONTRACT.md`; `C/docs/ROUTEVOICE-PROPOSED-PHYSICAL-GOAL-2026-10-13.md`).
- **Logical storage, full recognizer (W11, services moved from harness):** 28,641,280 B → **17,497,600 B** (saved 11,143,680 B, 38.91%), 0 round-trip mismatches over all original bytes (`F/w11-taalas-e2e/RESULTS.md` table; `storage-accounting.json`). Including the 8,847,360 B of five pre-existing onboard tables (embedding/head, source K/V index/book) → **26,344,960 B**. Frontend uses the model's own INT8 + FP32 scale + offset, reconstructed with separately rounded multiply then add (8,298,240 → 2,090,240 B, bit-exact over 2,073,600 weights) (`O/floorplan/RESULTS.md` §Exact native frontend; `OVERNIGHT-PROGRESS.md` 03:29 entry).
- **Earlier logical-payload figures (different scopes):** K64 ideal payload incl. unchanged initializers 25,987,246 B (14.29% larger than K128) (`C/docs/TAALAS-K64-QUALITY-RESULT.md`); per-tensor 4-bit export 18,222,920 B (`C/docs/SINGLE-DIE-FEASIBILITY-2026-09-19.md`).

## 3. Compute engine (1,280×320 array-port projection)

- **Arithmetic identity:** `w = 16·high + low`, `a·w = (a·high)·16 + a·low`; 16 shared partials `a·0 … a·15` per input; partials fit signed 13 bits (±3,825 for a ∈ [−255,255]); recombined product signed 17 bits (±65,025) (`C/docs/TAALAS-SHARED-PARTIAL-PRODUCTS.md` para 1–3). Scalar test exhausts 130,816 input pairs (same).
- **Datapath widths:** signed 9-bit centered activation, 4-bit index, UINT8 representative, 13-bit partial, 17-bit product, 320 × signed **27-bit accumulators**, 32-bit activation sum and correction (`O/fabric-k64/CONTRACT.md`; `O/fabric-k64/rtl/engine.sv` l.~13–25).
- **FSM (`taalas_serial_engine`):** IDLE → LOAD (accept one activation, add to activation_sum, register 16 partials `in_data × d`) → INDEX (array_read_enable; capture 1,280-bit index row = 320 × 4 bits; map each nibble through its book `(codebook_row_domain, index)` to a UINT8 representative latch) → ACCUM (each of 320 lanes adds `sext(partial[rep[3:0]]) + (partial[rep[7:4]] << 4)`) → next row or, after row 1,279, OUTPUT (one column per cycle: `accum[col] − activation_sum × zero_point[col]`) (`O/fabric-k64/rtl/engine.sv` l.106471–107734; lines 1197–1198 for low/high select).
- **FP32 affine:** `taalas_fp32_affine`, three globally-stalled stages using Berkeley HardFloat recoded modules (`iNToRecFN`, `mulRecFN`, `addRecFN`, `recFNToFN`), RNE with independent rounding: combined = act_scale × weight_scale; scaled = int × combined; result = scaled + bias; 5 exception flags (`O/fabric-k64/rtl/taalas_fp32_affine.sv`). Wrapper `taalas_projection_affine` latches one runtime activation scale per vector (`.../taalas_projection_affine.sv`).
- **Top variants:** `rv_k64_sc_rom` (indices as standard-cell constant logic, `taalas_index_fabric`) and `rv_k64_array_port` (1,280-bit asynchronous row-read port to an external index array; testbench fabric is a functional model) (`O/fabric-k64/rtl/rv_k64_*.sv`; `O/fabric-k64/CONTRACT.md`).
- **Cycles:** integer 4,160 = 3×1,280 + 320; FP32 4,163 (+3 drain) (`O/fabric-k64/CONTRACT.md`). Fix 1 (register before affine) → 4,164; fix 2 (PREP state + per-group look-ahead registers) → **4,165** (`F/w10-route/pipe/README.md`; `F/w10-route/pipe2/README.md`).
- **MACs per projection:** 409,600 (`F/w10-route/RESULTS.md` power block, `macs_per_projection`). 98.391 MAC/cycle (`O/floorplan/RESULTS.md` l.90).
- **Physical-ization steps:** W9 `engine_local.sv` / `buf-v4`: 10× duplicated row registers (each drives 32 lanes) + ABC buffering, max non-clock fanout 16 (was 11,359) (`O/engine-buffered/RESULTS.md`; `OVERNIGHT-PROGRESS.md` 06:04); local per-group partial products (`local_partials_g0..g9`, `O/engine-buffered/rtl/engine_local.sv` l.615–831) cut global-route overflow 3.37M → 260k (`C/AGENTS.md`).
- **Clock:** initial contract 20 ns (`O/fabric-k64/CONTRACT.md`); final **150 ns (6.67 MHz)**. Fix-2 routed, extracted SPEF, all 9 corners: setup WNS TT +67.6 ns, nom SS +21.6 ns, max SS +8.34 ns (worst), hold worst +0.300 ns; 0 setup/hold violations; DRT 0; GRT overflow 9; slew/cap-limit counts remain 902,170 / 24,383 at worst corner (`F/w10-route/pipe2/README.md`; `.../evidence/sta-postpnr-summary.rpt`). Fix-2 DRC/LVS/antenna "added when signoff finishes" (not yet reported).
- **Real-time requirement:** "≈0.6 G multiply-accumulates/s: encoder ≈7.37 M MAC per frame × 50 frames/s, plus ≈21.5 M MAC per decoded token at ~4 tokens/s, plus producer K/V" (`O/floorplan/LEAD-GUIDANCE-2.md` l.23). One engine at 150 ns = 409,600/(4,163×150 ns) ≈ 0.66 GMAC/s (`O/floorplan/MEASURED-ENGINE-UPDATE.md` l.57). See §8 for a conflicting workload measure.
- **Engine area/power (sequence of measurements):** routed die 22.74 mm² (std-cell 12.41 mm², utilization 0.551, 1,894,271 instances; closure pass 2) (`F/w10-route/closure-lead/final-metrics-pass2.json`). Routed activity-annotated TT power: first route 0.158 W / 98.7 µJ / ≈241 pJ/MAC (97.7% pins annotated) (`F/w10-route/routed-power-lead/RESULTS.md`); closure 0.168 W / 104.9 µJ / 256 pJ/MAC (68% annotated) (`OVERNIGHT-PROGRESS.md` release table); **fix 2 0.188 W (seq 24.3, comb 142, clock 21.5 mW) / ≈117 µJ / ≈287 pJ/MAC, 67.5% pins annotated** (`F/w10-route/pipe2/README.md`). Activity = one real-speech vector, zero-delay mapped-cell SAIF recorded at 20 ns and rescaled ×15/2 to 150 ns (`.../pipe2/evidence/activity-results.json`). Engine power excludes the index array (`power_scope`).
- **Index array for this projection (W6):** pitch-matched 1,280-row bank 1,004 × 2,258.81 µm = 2.26784524 mm² = **5.536731543 µm²/selection incl. analog readout and local wiring**; DRC 0 (selected deck, density/antenna excluded); all 1,638,400 bits read back; Netgen LVS unique match (1,643,520 raw devices), doubled-width negative rejected (`O/taalas-pitch/RESULTS.md`). Bank-wide WL/precharge fails at 60 ns; guarded 120 ns passes sampled SS (`OVERNIGHT-PROGRESS.md` 04:13, 04:26). INFERRED: at 150 ns the engine requests a row every 3 cycles = 450 ns, above the 120 ns protocol. Earlier W5 weight-fetch energy 62–78 pJ per 32-lane read ≈ 2 pJ/MAC (`OVERNIGHT-PROGRESS.md` 04:57).

## 5. Verification methodology

- **Proof taxonomy P0–P9** (idea → software → numerical reference → RTL block → connected RTL → open-flow physical → FPGA → foundry signoff → silicon → product); every label applies to a named artifact (`MASTER_GOAL.md` §Proof taxonomy). Ten evidence rules incl. separate claims for quality/parity/RTL/FPGA/density/power, index ≠ weight, held-out data, pinned revisions (same, §Evidence rules).
- **Projection bench:** 54 vectors (1 captured speech-derived + 53 integer fixtures), 17,280 integer + 17,280 FP32 outputs, 4 mid-vector resets (LOAD/INDEX/ACCUM/OUTPUT), 104,112 stalls; independent dense NumPy + scheduled shared-partial references; actual-matrix accumulator bound audit for [−255,255] (`O/fabric-k64/RESULTS.md`). Re-run at mapped-netlist and routed-netlist level (zero-delay): routed replay 54/54, cycles_sum 300,952 = expected (`F/w10-route/RESULTS.md` §Post-layout). SDF timing simulation unsupported by available simulators (same).
- **Full recognizer:** PCM → frontend → 6-layer encoder → adapter/K/V producer → greedy decoder → EOS on one common clock; pass = token IDs + 18/18 output hashes + identical clock count (delta 0 vs byte-ROM v2) + render; exhaustive responder readback (565,960 enc/dec packets, 2,074,560 frontend, 163,840 position) (`F/w11-taalas-e2e/RESULTS.md`).
- **Physical arrays:** DRC (selected GF180 deck), GDS bit readback vs independently unpacked K64 indices, Netgen LVS against a source-derived netlist, planted-error/wrong-width negative controls (`O/taalas-pitch/RESULTS.md`; `F/w13-arrays/RESULTS.md`).
- **Claim gating:** "a result is listed as PASS only after the lead re-ran or read the actual output. Worker claims are listed as 'claimed'" (`OVERNIGHT-PROGRESS.md` l.7). Root review + independent audit + SSD archive before tally credit (`C/docs/ROUTEVOICE-V1-CURRENT-DESIGN-2026-10-12.md` l.15). Failures preserved, not overwritten (e.g. `F/w11-taalas-e2e/FAILURES.md`; `O/fabric-k64/RESULTS.md` failures).
- **Hashing/backup:** SHA-256 pins for model, tensors, packed indices, books (`O/fabric-k64/RESULTS.md` §Identity); build/tool/binary pins (`F/w11-taalas-e2e/{build-input-pins,binary-pin,tool-pins}.json`); pod backup to public HF dataset `sanjuhs/routevoice-pod-final-20261022`, 105,827/105,827 files re-hashed (`OVERNIGHT-PROGRESS.md` 22 Oct 18:36).
- **Accuracy protocol:** calibration → single development validation → single reserved test; decisions hashed before inference; fresh native process per utterance (VAD crop-state fix); paired speaker-cluster bootstrap (`C/docs/TAALAS-K64-QUALITY-RESULT.md`).

## 7. Known limitations stated in the docs

1. Engine power is zero-delay, one vector, no glitches; fix-2 annotation only 67.5% (`F/w10-route/pipe2/README.md`). Slew/cap-limit violations remain in every run.
2. Fix-2 DRC/LVS/antenna not yet reported; closure had 4 antenna nets open (`OVERNIGHT-PROGRESS.md` release table).
3. Full-recognizer RTL uses behavioral index/book ROMs, not the array netlist; no physical cycle time for the combinational frontend decoder (`F/w11-taalas-e2e/RESULTS.md` last paras; `OVERNIGHT-PROGRESS.md` §NOT done item 4).
4. W11 F64 is an integration repeat, not new held-out accuracy; connected negative suite not rerun (`F/w11-taalas-e2e/RESULTS.md`).
5. Reserved-test pass is a point estimate; noise/other bootstrap upper bounds exceed +2 pp; only 20 speakers per stratum; synthetic white noise; upstream training overlap unknown; live streaming quality not measured (`C/docs/TAALAS-K64-QUALITY-RESULT.md`).
6. Arrays: selected DRC excludes density/antenna; no foundry signoff; provisional Liberty; drivers/latches/escape outside macro; full-bank WL/PC fails 60 ns (`F/w13-arrays/RESULTS.md`; `O/taalas-pitch/RESULTS.md`).
7. Floorplans are abstract macros with assumed loads; two-die cut is area-balanced, not an implemented encoder/decoder partition; link costs assumed (`O/floorplan/RESULTS.md`).
8. Complete recognizer power, real-time service calendar, and minimum die count remain unknown/unproved (`C/docs/TAALAS-POWER-EVIDENCE-BOUNDARIES-2026-10-03.md`; `C/docs/TAALAS-REAL-TIME-WORKLOAD-BOUNDARIES-2026-10-03.md`; `C/docs/TAALAS-FULL-PIPELINE-EVIDENCE-MATRIX-2026-10-03.md`).
9. RTL as written is ≈1.2 cm² of logic; mutable state is flops in generic synthesis (`F/w12-synth/RESULTS.md`).
10. Public HF backup flagged for possible privacy change (`OVERNIGHT-PROGRESS.md` §Biggest open items 4).
11. GF180 is not the intended SCL process; open-PDK results are research evidence only (`MASTER_GOAL.md`; `C/tools/lock.json` signoff_scope).
