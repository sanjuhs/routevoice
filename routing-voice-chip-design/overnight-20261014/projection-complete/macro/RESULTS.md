# W8 Stage 1 — W6 macro integration views

**W8-STATUS: Stage 1 delivered; geometrical pin coverage passes. Full-bank timing/power remain uncharacterized.**

Use `PITCH_BANK_R1280.lef`, `PITCH_BANK_R1280.v`, `PITCH_BANK_R1280.lib`, with the unchanged read-only source `../../taalas-pitch/r1280-v2/bank.gds` (relative from this directory). The source cell is `PITCH_BANK_R1280`. The generator/verification scripts and JSON receipts are retained here.

The macro interface is scalar `WL0`–`WL1279`, `OUT0`–`OUT1279`, `PC`, `VDD`, `VSS`. There is no physical macro clock pin and no invented one in these views. Each output is a real Metal2 receiver-output rectangle. Each wordline exposes the real leftmost 6.5 µm of its continuous Metal3 rail. PC exposes Metal4 near the upper left. VDD and VSS expose the full existing Metal4 spines and their original 0.8 µm square Metal5 pads, with original Via4 connectivity. The full spines allow horizontal Metal5 PDN straps to connect using Via4; PDN generation and electrical qualification remain the parent physical run's responsibility.

`verification.json` reports all 2,563 names match GDS labels, all LEF port rectangles are subsets of actual same-layer GDS metal, wordline left access shares the same top-level physical rectangle as its label, and supply M4-to-M5 Via4 exists. It does not establish full-bank LVS. Internal IDX/OPEN labels are intentionally not external ports.

GDS bounds are x=0..1004, y=0.04..2258.85 µm. Preserving the original GDS coordinates requires LEF origin (0,0), SIZE 1004 × 2258.85 µm. The LEF envelope is 2.2678854 mm²; material bounding-box footprint is 2.26784524 mm². The 0.00004016 mm² difference is the 0.04 µm bottom boundary allowance, not a layout change. All 409,600 original selections are retained by using the unchanged GDS, whose SHA-256 is in the receipts.

Metal1 is blocked throughout the macro, and Metal2 is conservatively blocked over the array portion. Receiver-region Metal2 and all Metal3/4/5 obstacles use exact Manhattan decomposition of actual geometry minus exported pin metal. Consequently the existing unoccupied higher-metal corridors remain available for output escape. This is not a claim that 1,280 outputs have already escaped or are routable in a full design. The Metal3 obstruction list has 119,144 rectangles; the LEF is approximately 5.4 MB.

The Liberty file is explicitly an engineering proxy. W6 measured 23.376321 ns sampled SS settling from wordline command and passing 60 ns reuse in a partial extracted case. The integrated protocol proposed by W8 places WL assertion 20 ns after PC deassertion; therefore this view uses a PC-to-OUT combinational delay of 44 ns (20 + rounded 24). It invents no synchronous clock, setup/hold characterization or min-period proof. PC-referenced arcs omit the independent WL-to-output paths and decoder hazards; timing closure of this model cannot establish complete macro timing closure. A 1 ns output slew is an assumption, and the same provisional model across integration corners does not constitute independent corner characterization.

Input caps are nonzero engineering sensitivity loads: WL=2 pF and PC=10 pF. W6 group extraction gives explicit WL capacitance up to 0.02650314 pF and PC capacitance 0.15156014 pF for a 32-lane group. Scaling those wiring numbers by ten and adding nominal MOS gate-area estimates from the PDK oxide values provides a basis for the rounded assumptions; complete common-rail, overlap, coupling, voltage-dependent charge and distributed effective load are uncharacterized. `timing-model.json` records the derivation and limitations. No macro power or leakage is supplied, and missing power is not zero power.

The first narrow supply-pad abstract is preserved as `v1-PITCH_BANK_R1280.lef`, with its receipts. Three bounded generator failures/interruptions are preserved in `generator-first-attempt.txt`, `generator-second-attempt.txt`, and `generator-third-attempt.log`; the successful generator and independent geometry verifier both exit 0. A later bounded local OpenSTA parser check found missing threshold declarations. With parent authorization, the original Liberty and receipt were preserved as `pre-parser-fix-*`, and explicit input/output50% and slew20/80% engineering threshold conventions were added to the file and generator. Direct Nix-store OpenSTA2.7 then accepted the Liberty without warnings (exit0); receipt is `../power/liberty_parser_check.log`. This is parser acceptance, not timing characterization.
