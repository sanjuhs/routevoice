# Physical evidence rules for this trial

The resolved flow uses GF180MCU-D `gf180mcu_fd_sc_mcu7t5v0`, with default nominal RC / TT 25 C 3.3 V, and nine RC/PVT combinations: nominal/minimum/maximum RC crossed with TT 25 C 3.3 V, SS 125 C 3.0 V, FF -40 C 3.6 V. `VDD_PIN_VOLTAGE` is not a modern resolved field; Liberty operating conditions select the timing/power voltage. The explicit LIB dictionary is the governing evidence.

Clock 20 ns. Resolved IO delay constraint is 20 percent (4 ns), output load 72.91 fF, driving cell inv_1/ZN, uncertainty 0.25 ns, transition 0.15 ns, timing derating 5 percent. ARRAY-PORT is constrained as an external index interface; meeting its IO timing does not prove a custom array fits the index-read budget.

KLayout DRC is enabled in the input configs, but its runset resolves null. A skipped KLayout step cannot receive pass credit. `run_klayout_drc.sh` is a supplemental launcher for the supplied GlobalFoundries rule-deck runner (deep, variant D, density and antenna enabled). It requires an installed Python environment with docopt and klayout.db; the Nix environment is preferred. Do not present an unexecuted launcher as a DRC result.

`power.tcl` is the post-route power recipe. Run separately per Liberty/PVT and extracted SPEF. It records default power, SAIF/VCD activity-annotation coverage, annotated power and the twenty highest-power instances. Units are printed in the retained invocation log. The actual VCD contains one hash-bound saved real-activation vector at a 20 ns clock; no new speech capture. If OpenSTA cannot match internal names after flattening, report the annotation coverage and qualify default-propagated/internal activity. No measured mW, energy or actual operating MHz until the command runs and timing supports the frequency. A real-activity RTL trace without netlist annotation is not activity-based power.

Routed footprint and placed cell area are different. Standard-cell fixed ROM is a comparator; any SC-ROM minus ARRAY-PORT area difference includes optimization and routing effects and is not a measured custom-array cost. If flattened mapping loses category ownership, report that accounting limitation rather than inventing an arithmetic/fabric split.

The comparison excludes package pads, upstream activation quantizer and complete recognizer. SC-ROM includes all weight/metadata logic and FP32 output processing at its logical boundary. ARRAY-PORT additionally excludes the custom index array and its physical peripheral circuits.

Superseded completed views may be stored as `.gz` to maintain the internal-disk floor. `evidence/superseded-archives.json` records their original SHA-256 and verifies decompressed identity before removing the raw duplicate. Active state input references are protected. Restore a historical checkpoint with `gunzip` for its archived views before resuming that historical state JSON. All archives remain inside this workspace.

ARRAY-PORT `30-checker-powergridviolations` reports zero generated-grid violations. This is a placement-stage connectivity/construction check, not an IR-drop, electromigration, routed DRC or sub-watt result. A 1-second process sample in `evidence/array_port-repair-sample.txt` places the active repair process in `RepairDesign::repairNet` and STA delay recalculation; it establishes active compute, not convergence.

Completed synthesis logs and large Yosys JSON netlist views are also losslessly archived as `.gz`; `evidence/synthesis-archives.json` binds their decompressed hashes. The raw Verilog netlists, compact statistics, commands and state manifests remain directly readable. This freed space without discarding evidence.
