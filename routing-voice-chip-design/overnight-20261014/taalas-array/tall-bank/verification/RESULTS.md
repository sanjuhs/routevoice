# Independent tall-bank verification

The saved **320-row bank 3** passes full independent physical LVS: **414,720 extracted devices** match the packed-model-derived reference by exact connectivity and W/L, and monolithic Netgen reports a unique match with **no property errors** in 42.27 s. All ten disjoint 41,472-device partitions also pass Netgen. The shared-net audit finds exactly the intended 320 wordlines, PC, VDD and VSS shared across all ten lane groups, with no unintended cross-group nets. See `bank3-v1/lvs-result.json`, `connectivity.json`, `partition-audit.json` and `full-bank-netgen.log`.

The comparison strips only unique hierarchical node prefixes under a checked 207,439-node bijection; it changes neither devices nor connectivity. Receiver precharge PMOS width is 2.88 µm; keeper/inverter PMOS/inverter NMOS widths are 0.36/0.72/0.36 µm. Every device length is 0.28 µm; access NMOS width is 0.36 µm. A deliberate single-device precharge-width change from 2.88 to 5.76 µm is rejected with a property error. Netgen still prints its topology-match phrase in that negative control, so the pass checker requires both unique match and absence of property errors. The failing control is preserved.

Independent readback reopened both assemblies and decoded programmed Via1 sites. The four 320-row banks contain all **1,638,400 bits / 409,600 indices**, with **zero mismatches**, using striped `logical_row = bank + 4*local_row`. The optional one-bank 1,280-row assembly also has **zero mismatches** over all model bits. Both were checked against a fresh decode of the original rectangular packed model and against W2b frozen RTL. This does not grant the 1,280-row variant full-bank LVS credit.

The same full-bank Magic extraction retains `bank3-v1/extracted-cap.spice`, containing 1,570,554 explicit capacitance elements. Wordline incident explicit capacitance spans **533.6565–614.14205 fF**; PC is **925.61188 fF**. Every wordline and PC drives 1,280 actual transistor gates. `control-capacitance.json` includes all 1,280 bitline inventories, connected-drain populations and a ranking by incident explicit capacitance. These are lumped wiring capacitances, not distributed RPEX or transistor intrinsic capacitance, and are not an energy or timing result.

Magic extraction completed in 554.89 s on one nice CPU thread. After export finished, its closed intermediate `.ext` was compressed from 349,984,289 to 23,110,492 bytes and decompressed in a streaming SHA256 check before removing the uncompressed copy. `bank3-v1/ext-compression-receipt.json` records both hashes and the restoration command. Both original LVS and capacitance SPICE exports remain uncompressed. All writes are in this verification directory; no git or cloud was used.

Scope limits: this is array plus strengthened analog receivers and actual joining/control/power wires. Physical row decoder/drivers, PC driver, phase generation, output bank mux and output latches are excluded. Full LVS covers bank 3 only. Other banks have independent mask readback, not independent full LVS in this report. Parent DRC reports remain separate. Whole-macro compatibility, complete-row energy, distributed-control timing and real-time projection performance are unproved.

Exact commands are in `COMMANDS.md`; machine evidence is in `results.json`.
