# Helmet design package

Original design deliverables preserved with the RouteVoice Version 1 milestone.

| Artifact | Contents |
|---|---|
| [Product brief](Routing-Helmet-V1-Product-Brief.pdf) | 14-page September 2026 product definition: user experience, typed capabilities, deterministic authority, physical packaging and planning assumptions |
| [Product brochure](Routing-Helmet-V1-Brochure.pdf) | Six-page presentation of the helmet concept and proposed interaction |
| [V4 web model](Routing-Helmet-V4-Web.glb) | The optimized GLB used by the live helmet website; 49 named mesh nodes, about 1.8 MiB |

The PDFs and GLB are copied unchanged from the original project. See [source paths and checksums](../milestone-evidence/asset-provenance.json).

The brief and brochure predate the final placement sheets and V4 gallery, so they preserve earlier concept imagery. Their performance, cost and integration statements are planning context from that period. Use the [root milestone report](../../README.md) for current evidence and the expanded design gallery.

These are concept and storytelling deliverables, not production CAD, fabricated hardware or helmet certification evidence. Open the GLB in a glTF-capable viewer to inspect the assembly, or use the [live website](https://routing-module-180.vercel.app).
